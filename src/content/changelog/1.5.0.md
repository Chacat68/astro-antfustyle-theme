### 🚀 新功能

- **Studio 首页展示台**：新增大圆角 Hero 舞台与完整的「关于我」区块，集中展示个人介绍、经历、创作理念与联系方式。
- **全站 Studio 壳层**：统一博客、项目、友链、相册、画廊、日志等页面的内容轨宽、标题层级、胶囊 Tab、列表与卡片样式。
- **更清晰的站点导航**：导航入口统一使用文字展示，搜索、语言、主题与 RSS 保留为功能按钮；移动端在 1024px 以下自动收进菜单面板。
- **相册体验增强**：照片墙支持更均衡的瀑布流排列，新照片按时间戳 ID 优先展示；继续完善照片与 AI 作品集内容。

### 🐞 修复

- **搜索面板定位**：修复搜索浮层在 sticky 导航与不同视口下偏移的问题，统一相对视口居中。
- **多语言跳转**：修复语言切换后首页 `#about` 锚点丢失的问题，并完善中英文页面的 fallback 与 hreflang 处理。
- **SEO 路由一致性**：统一文章 slug 的大小写处理，修复 sitemap、canonical 与实际产物不一致的问题；英文 fallback 页面不再进入索引。
- **图片查看器加载**：修复图片查看器初始化与页面切换之间的竞态，改为首次点击图片时才加载 viewerjs 资源。
- **响应式与可访问性**：修复窄屏导航、标题区、列表间距、暗色模式对比度及触控目标等细节问题。

### 💅 重构 / 性能

- **背景系统轻量化**：全站默认背景改为 CSS Ambient 氛围背景，并移除历史 Three.js 故障背景代码与运行时依赖。
- **按需加载**：Pagefind、viewerjs 与相关样式改为在实际使用时加载，减少首页与文章页的首屏资源。
- **正文图片优化**：正文首图使用 `eager` 与高优先级加载，其余图片默认使用 `lazy` 与异步解码；避免构建期拉取 COS 原图尺寸导致部署超时。
- **Markdown 与 SEO 管线**：补充 Markdown 纯文本端点、AI 抓取入口、robots/sitemap 过滤与文章元数据处理，统一 canonical、RSS 与 Open Graph 地址。
- **安全策略收紧**：完善 Cloudflare 静态资源响应头与 CSP 白名单，同时兼容 Pagefind Worker、Giscus、统计脚本和文章内嵌媒体。

### 🏡 内容与文档

- **新增文章**：发布港乐集《关淑怡：从甜歌到前卫》，补充音乐、粤语与作品背景内容。
- **相册更新**：新增深圳、佛山、广州与香港等地的近照，持续整理摄影内容。
- **项目与页面维护**：更新项目展示、文章分类和页面文案，统一中英文界面文字。
- **文档完善**：新增并同步架构约定、设计系统、性能规范、SEO 指南与 Cloudflare 部署流程，记录图片、缓存、路由和远程 Loader 的维护方式。
